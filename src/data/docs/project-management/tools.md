# PM Tools cho Developer

## GitHub Projects

Tốt nhất nếu team đã dùng GitHub. Tích hợp trực tiếp với Issues và PRs.

**Khi nào dùng**: Open source, solo projects, team nhỏ tech-heavy.

## Linear

Modern, fast, keyboard-first. Được thiết kế cho engineering teams.

```
Cycles (= Sprints) → Issues → Sub-issues
```

**Khi nào dùng**: Startup, product team muốn tool nhanh và đẹp.

## Jira

Powerful nhưng phức tạp. Overkill cho team nhỏ.

**Khi nào dùng**: Enterprise, team lớn, cần custom workflows phức tạp.

## Notion

Linh hoạt nhất — database, docs, và project tracking trong một.

**Khi nào dùng**: Solo projects, khi cần kết hợp docs và tasks.

## Recommendation

| Team size | Tool |
|-----------|------|
| Solo | Notion hoặc GitHub Projects |
| 2-5 người | Linear hoặc GitHub Projects |
| 5-20 người | Linear hoặc Jira |
| 20+ người | Jira |
