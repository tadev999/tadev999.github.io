# Agile cơ bản cho Developer

## Agile là gì (thực sự)?

Agile không phải là họp daily standup. Agile là **mindset** về cách deliver value liên tục thay vì big-bang release.

**4 giá trị cốt lõi:**
1. Individuals and interactions > processes and tools
2. Working software > comprehensive documentation
3. Customer collaboration > contract negotiation
4. Responding to change > following a plan

## Scrum trong 5 phút

| Ceremony | Tần suất | Mục đích |
|----------|----------|----------|
| Sprint Planning | Đầu sprint | Chọn task cho 2 tuần |
| Daily Standup | Hàng ngày | Sync nhanh, unblock |
| Sprint Review | Cuối sprint | Demo cho stakeholders |
| Retrospective | Cuối sprint | Cải thiện process |

## Kanban — đơn giản hơn Scrum

Nếu solo hoặc team nhỏ, Kanban thường phù hợp hơn:

```
Backlog → In Progress → Review → Done
```

Giới hạn WIP (Work In Progress) = 2-3 tasks để tránh context switching.
